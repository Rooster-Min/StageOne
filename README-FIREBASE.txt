7.2 Cloud beta: Authentication existente, Firestore usuarios/publicaciones y Storage. En consola activar Storage y revisar facturación. Revisar y publicar firestore.rules y storage.rules en sus respectivas pestañas Rules (subirlos a GitHub no los activa). No reemplazar reglas de otros servicios sin revisar. Las publicaciones nuevas públicas se envían a nube; anteriores mediante menú Sincronizar publicaciones anteriores. Los enlaces de descarga de multimedia son públicos para quien tenga el enlace: no usar contenido confidencial; eliminar un documento no revoca enlaces ni elimina archivos. Mensajes, likes, historias, playlists y fotos de perfil siguen locales. Prueba con dos cuentas antes de invitar usuarios. No probado contra Firebase real.
